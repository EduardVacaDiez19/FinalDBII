🚀 INICIO ULTRA RÁPIDO (5 PASOS)

1️⃣  INSTALAR DEPENDENCIAS
    cd clinica-dental-real
    npm install

2️⃣  CONFIGURAR .env
    Copia .env.example a .env
    Edita las credenciales de tus bases de datos

3️⃣  CREAR BASE DE DATOS SQL SERVER
    Ejecuta en SSMS o sqlcmd en ORDEN:
    ✅ database/sql/CreaciondeTablas.sql
    ✅ database/sql/StoredProcedures.sql
    ✅ database/sql/Triggers.sql
    ✅ database/sql/Transacciones.sql
    ✅ database/sql/CreaciondeIndices.sql

4️⃣  CREAR BASE DE DATOS MONGODB
    mongosh < database/mongodb/mongo.js

5️⃣  INICIAR SERVIDOR
    npm start
    Abre: http://localhost:3000

📋 ESTRUCTURA DE TU PROYECTO

✅ TU BASE DE DATOS SQL SERVER:
   • ClinicaDentalDB
   • Tablas: Usuarios, Roles, Pacientes, Doctores, Citas, Servicios, Pagos
   • Stored Procedures: ValidarLogin, sp_AgendarCita, sp_RegistrarPacienteWeb, etc.
   • Triggers: Auditoría, validaciones automáticas
   • Transacciones: RealizarPagoSeguro, sp_ReprogramarCita, etc.

✅ TU BASE DE DATOS MONGODB:
   • ClinicaDentalNoSQL
   • Colecciones: Expedientes, Proveedores, Encuestas, Marketing
   • Polimorfismo en especificaciones de productos
   • Documentos anidados (odontogramas)

📡 ENDPOINTS PRINCIPALES

POST   /api/auth/login                  - Login (ValidarLogin SP)
GET    /api/pacientes                   - Listar pacientes
POST   /api/pacientes                   - Registrar (sp_RegistrarPacienteWeb)
DELETE /api/pacientes/:id               - Eliminar (sp_EliminarPacienteWeb)
GET    /api/citas                       - Listar citas
POST   /api/citas                       - Agendar (sp_AgendarCita)
GET    /api/expedientes/paciente/:id    - Ver expediente (MongoDB)
GET    /api/inventario/productos        - Ver inventario (MongoDB)
GET    /api/encuestas                   - Ver encuestas (MongoDB)

🔧 SOLUCIÓN DE PROBLEMAS

❌ "Cannot connect to SQL Server"
   → Verifica SQL Server esté corriendo
   → Revisa credenciales en .env
   → Puerto 1433 debe estar abierto

❌ "Cannot connect to MongoDB"
   → Verifica: mongod --version
   → Inicia MongoDB
   → Puerto 27017 debe estar disponible

❌ "Stored Procedure not found"
   → Ejecuta los scripts SQL EN ORDEN
   → CreaciondeTablas.sql PRIMERO
   → Luego StoredProcedures.sql
